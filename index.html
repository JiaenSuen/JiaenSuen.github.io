Project / Research Journey

Development process behind key work.

This section is useful for graduate applications because it shows ownership, iteration, and research maturity beyond final project outcomes.

01

Problem Framing

Defined a practical research question: how to preserve reliable 3D perception quality on embedded hardware with limited compute and a small-baseline stereo setup.

Output: project scope, constraints, evaluation direction
02

Prototype and Baseline

Built initial stereo depth and object detection components, then analyzed bottlenecks in latency, integration quality, and scene-level robustness.

Output: baseline implementation and failure cases
03

System Optimization

Refined the pipeline for embedded deployment by prioritizing model size, inference speed, and practical calibration assumptions.

Output: improved pipeline and documented trade-offs
04

Research Communication

Organized the work into a clearer technical narrative, including method motivation, implementation details, limitations, and possible future extensions.

Output: paper / report / demo-ready explanation
